# DBM YT-Automation

DBM YT-Automation by BITBEAST PRIVATE LIMITED.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/69a2af5913760609ab15a9a9/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **DBM YT-Automation** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/69a2af5913760609ab15a9a9/releases/latest) and reinstall.
